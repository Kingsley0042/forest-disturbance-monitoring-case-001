# Case 001 — Map Outputs

This folder contains the map outputs for **The Forest Files: Forest Disturbance Monitoring and Verification**.

- `Forest_Files_Case_001.png` — Study Area Overview
- `Forest_Files_Map_2_Vegetation_Change.png` — Vegetation Change Analysis, 2023–2025
- `Forest_Files_Map_3_Candidate_Verification.png` — Candidate Disturbance Verification

These maps show potential vegetation disturbance identified through satellite-based screening. They do not independently confirm deforestation.
